# BCD Interface

## Overview
A BCD (Binary Coded Decimal) Interface module that implements the conversion and interfacing logic for BCD adder operations. This design translates binary inputs into BCD format, performs arithmetic operations, and outputs the results in Binary Coded Decimal representation.
